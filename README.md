# FocusFlow 🏄🏻‍♂️
A Chrome Web Extension with many useful features. I combined features of many mini extension together in one browser extension. (Currently working features are only Password Strength Checker & Color Picker)

## Download ⬇
If you want to use this chrome browser extension, following are the steps:
1. Download all files.
2. Unzip the files.
3. Open your browser & Go to extension section.
4. Enable developer mode.
5. Load unpacked files & You are done.
